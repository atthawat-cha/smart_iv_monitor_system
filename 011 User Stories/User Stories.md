### IoT
- **เซนเซอร์วัดน้ำหนัก:** Load Cell แบบแขวนที่สารน้ำโดยตรวจจับจากน้ำหนัก
- **โมดูลแปลงสัญญาณ:** HX711 Amplifier Module (แปลงสัญญาณอนาล็อกจาก Load Cell เป็นดิจิทัล)
- **บอร์ดไมโครคอนโทรลเลอร์:** ESP32 (มี Wi-Fi ในตัว เหมาะกับการส่งข้อมูล)
- **ซอฟต์แวร์:** Arduino IDE (สำหรับเขียนโปรแกรมลง ESP32)
- **การรับส่งข้อมูล:** ส่งข้อมูลผ่าน API - HTTP POST ของบอร์ด

📝 ขั้นตอนการทำโดยสังเขป
1. การต่อวงจรฮาร์ดแวร์ต่อ สายไฟ 4 เส้นจาก Load Cell เข้ากับโมดูล HX711 (ตามสีสายไฟ E+, E-, A+, A-)ต่อ โมดูล HX711 เข้ากับ ESP32 (ต่อไฟ VCC/GND และสายข้อมูล DT/SCK เข้ากับขา GPIO ของ ESP32)
2. การสอบเทียบเซนเซอร์ (Calibration)ใช้ห้องสมุด (Library) ชื่อ HX711 ใน Arduino IDEเขียนโค้ดเพื่อหาค่า Calibration Factor โดยวางวัตถุที่ทราบน้ำหนักจริงลงบน Load Cell เพื่อตั้งค่าให้เซนเซอร์อ่านค่าได้เที่ยงตรง
3. การอ่านค่าแบบ Real-time และเชื่อมต่อเครือข่ายเขียนโค้ดสั่งให้ ESP32 อ่านค่าน้ำหนักจาก HX711 อย่างต่อเนื่องในฟังก์ชัน loop()ใช้คำสั่งเชื่อมต่อ ESP32 เข้ากับ Wi-Fi บ้านหรือที่ทำงานของคุณ
4. การส่งข้อมูลเข้าฐานข้อมูล (เลือกได้ 2 วิธีหลัก)
	1. วิธีที่ 1 (ผ่าน Web API - แนะนำสำหรับ MySQL):สร้างไฟล์สคริปต์ (เช่น PHP หรือ Node.js) ไว้บนเซิร์ฟเวอร์เพื่อรอรับข้อมูลให้ ESP32 ใช้คำสั่ง HTTP POST ส่งค่าน้ำหนักไปยัง URL ของสคริปต์นั้น เพื่อให้สคริปต์บันทึกข้อมูลลง MySQL อีกทีหนึ่ง
	2. วิธีที่ 2 (ส่งตรงเข้า Cloud - แนะนำสำหรับ Firebase):ใช้ห้องสมุด Firebase-ESP32 ใน Arduino IDEสั่งให้ ESP32 ส่งค่าน้ำหนักยิงตรงเข้า Firebase Realtime Database ได้โดยไม่ต้องมีสคริปต์คั่น
