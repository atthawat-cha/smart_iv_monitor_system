# raise2-homework/

โฟลเดอร์นี้แยกต่างหากจาก `000-Project-Code/smis/` (ระบบ SMIS จริง) โดยเจตนา — ใช้เก็บงานการบ้านของวิชา **RAISE2 Module 2** เท่านั้น

**หมายเหตุถึงอาจารย์:** ระบบ SMIS จริงออกแบบให้ใช้ **PostgreSQL + Prisma** (ดู `000-Project-Code/smis/apps/api/prisma/schema.prisma` และ `014 Database/Database.md`) ตั้งแต่ Sprint 1 ของแผนพัฒนาแล้ว งานการบ้านที่กำหนดให้ใช้ **Firestore** ในสัปดาห์นี้จึงถูกทำแยกไว้ในโฟลเดอร์นี้เป็น sandbox/prototype เฉพาะกิจ เพื่อฝึกตามที่คอร์สสอน โดยไม่กระทบ/ปะปนกับ schema และโค้ดจริงของโปรเจกต์

โครงสร้างข้อมูล Firestore ในโฟลเดอร์นี้ ออกแบบให้สอดคล้องกับ schema จริง (`Ward`, `Bed`) มากที่สุด ตามที่ระบุใน [`../SCOPE.md`](../SCOPE.md)
