- ภาพที่แสดงว่าข้อมูล private (`users/{uid}` หรือหน้า ward list) **เข้าถึงไม่ได้เมื่อยังไม่ล็อกอิน** — เช่น เปิดหน้าเว็บแบบ incognito ไม่ล็อกอินแล้วเห็น `permission-denied` error ใน console, หรือ UI แสดงข้อความให้ล็อกอินก่อน
