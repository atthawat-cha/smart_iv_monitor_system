## Problem

โรงพยาบาลยังคงใช้การตรวจสอบสารน้ำ (IV) แบบ Manual โดยพยาบาลต้องเดินตรวจทีละเตียง ส่งผลให้เกิดปัญหาหลัก ได้แก่

* สารน้ำหมดโดยไม่มีการแจ้งเตือน ทำให้เสี่ยงต่อความปลอดภัยของผู้ป่วย
* พยาบาลใช้เวลาเดินตรวจจำนวนมาก ลดเวลาที่ควรใช้ในการดูแลผู้ป่วย
* ไม่สามารถมองเห็นภาพรวมของทั้งวอร์ดหรือหลายวอร์ดได้แบบ Real-time
* ไม่สามารถจัดลำดับความสำคัญของเตียงที่ต้องได้รับการดูแลก่อน
* หากอุปกรณ์ IoT ขัดข้องหรือสารน้ำไหลผิดปกติ จะตรวจพบได้ช้า ส่งผลต่อประสิทธิภาพการรักษา

---

## Target User

### Primary Users

**Nurse**

* ตรวจสอบสถานะสารน้ำทุกเตียงผ่าน Dashboard
* รับการแจ้งเตือนเมื่อสารน้ำใกล้หมดหรือเกิดความผิดปกติ
* จัดลำดับการเข้าดูแลผู้ป่วยจาก Priority Queue

### Secondary Users

**Head Nurse**

* ติดตามสถานะของทุกวอร์ดแบบ Real-time
* วิเคราะห์สถิติการใช้งานและประสิทธิภาพของวอร์ด

### System Administrator

* จัดการอุปกรณ์ IoT และสถานะการเชื่อมต่อ
* จัดการผู้ใช้งานและสิทธิ์การเข้าถึง
* ตั้งค่าระบบและช่องทางการแจ้งเตือน

---

## Solution

**Smart IV Monitoring System (SMIS)** คือระบบติดตามปริมาณสารน้ำแบบ Real-time ที่เชื่อมต่ออุปกรณ์ IoT กับ Dashboard กลาง เพื่อช่วยให้บุคลากรทางการแพทย์สามารถติดตามสถานะของสารน้ำทุกเตียงได้จากศูนย์กลาง

### Key Features

* แสดงปริมาณสารน้ำแบบ Real-time พร้อมเปอร์เซ็นต์และปริมาณคงเหลือ (mL)
* คำนวณ **Estimated Time to Empty (ETE)** เพื่อคาดการณ์เวลาที่สารน้ำจะหมด
* แจ้งเตือนอัตโนมัติเมื่อสารน้ำใกล้หมด สารน้ำหมด อุปกรณ์ Offline หรือพบการอุดตันของการไหล (Occlusion)
* Priority Queue Engine จัดลำดับเตียงที่ควรได้รับการดูแลก่อนโดยอัตโนมัติ จาก Remaining %, Flow Rate และ ETE
* Dashboard แสดงภาพรวมทั้งโรงพยาบาล พร้อม KPI, กราฟ และสถานะของทุกวอร์ด
* Digital Twin Ward View จำลองผังวอร์ดจริงเพื่อให้เห็นภาพรวมได้อย่างรวดเร็ว
* Device Monitoring ติดตามสถานะอุปกรณ์ IoT เช่น Online/Offline, Battery และ RSSI
* รองรับการแจ้งเตือนผ่าน Dashboard, LINE OA, Telegram และ Email

### Future AI Capabilities

* Predictive Refill คาดการณ์เวลาที่ควรเปลี่ยนสารน้ำล่วงหน้า
* Anomaly Detection ตรวจจับพฤติกรรมการไหลที่ผิดปกติ
* Auto-Bag Change Detection ตรวจจับการเปลี่ยนถุงสารน้ำอัตโนมัติจากข้อมูลน้ำหนัก โดยไม่ต้องกดรีเซ็ตในระบบ

## Technology

### IoT Layer

* ESP32 สำหรับประมวลผลและสื่อสารข้อมูล
* Load Cell + HX711 สำหรับวัดปริมาณสารน้ำจากน้ำหนัก
* ส่งข้อมูลเข้าสู่ระบบแบบ Real-time

### Backend

* NestJS
* tRPC
* PostgreSQL
* Prisma ORM

### Frontend

* Next.js 15
* TypeScript
* Tailwind CSS
* shadcn/ui
* Framer Motion
* Recharts

### Real-time Communication

* Socket.IO / WebSocket

* Docker
* Vercel

## Expected Impact

### Clinical Impact

* ลดความเสี่ยงจากการที่สารน้ำหมดโดยไม่มีผู้ดูแล
* เพิ่มความปลอดภัยของผู้ป่วยจากการแจ้งเตือนเชิงรุก
* ตรวจพบความผิดปกติของอุปกรณ์หรือการไหลของสารน้ำได้รวดเร็วขึ้น

### Operational Impact

* ลดเวลาการเดินตรวจของพยาบาลมากกว่า **50%**
* ช่วยให้พยาบาลสามารถจัดลำดับการทำงานตามความเร่งด่วนได้ทันที
* รองรับการติดตามสถานะสารน้ำมากกว่า **100 เตียง** พร้อมกันจาก Dashboard เดียว
* ลดภาระการติดตามอุปกรณ์และเพิ่มประสิทธิภาพการบริหารจัดการวอร์ด

### Business & Digital Transformation

* ยกระดับโรงพยาบาลสู่ **Smart Hospital** ด้วยการติดตามข้อมูลแบบ Real-time
* สร้างฐานข้อมูลสำหรับการวิเคราะห์และพัฒนาระบบ AI ในอนาคต
* สนับสนุนการตัดสินใจด้วยข้อมูล (Data-driven Healthcare) ผ่าน Dashboard และ Analytics
* วางรากฐานสำหรับการขยายระบบไปสู่การติดตามอุปกรณ์ทางการแพทย์ประเภทอื่นในอนาคต
