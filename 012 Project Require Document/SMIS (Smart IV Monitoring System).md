# Root Cause

## อาการ / ผลลัพธ์ที่เห็นชัด

- งานเปลี่ยน IV แทรกกลางคันตลอดเวร ต้องหยุดงานที่ทำอยู่
- ญาติผู้ป่วยเป็นคนแจ้งก่อนพยาบาล
- เดินซ้ำเส้นทางเดิมทีละเตียง แทนที่จะรวบไปทีเดียว
- เวรที่งานหนัก รอบตรวจหลุด → IV หมดค้าง
- หัวหน้าหอไม่มีข้อมูลเชิงตัวเลขเรื่องภาระงานของทีม
### 5 Whys

```text
1. ทำไมงานเปลี่ยน IV ถูกแทรกตลอด?
   → รู้ว่า IV จะหมด ก็ต่อเมื่อมันหมดไปแล้วและมีคนมาเรียก

2. ทำไมรู้ช้า?
   → ประเมินได้แค่ตอนเดินผ่านเตียง = เป็น snapshot ไม่ใช่แนวโน้ม

3. ทำไมได้แค่ snapshot?
   → ดูระดับน้ำด้วยตา บอกได้แค่ "เหลือเท่าไหร่" ไม่บอก "อีกนานแค่ไหน"

4. ทำไมไม่รู้ว่าอีกนานแค่ไหน?
   → ไม่มีการวัดอัตราการไหลต่อเนื่อง ข้อมูลไม่ถูกบันทึก คำนวณล่วงหน้าไม่ได้

5. ทำไมถึงยังเป็นแบบนี้?
   → Workflow ออกแบบให้ตอบสนองหลังเกิดเหตุ (reactive) ไม่ใช่วางแผนล่วงหน้า
```

## 🎯 Root Cause

> [!important] **หอผู้ป่วยไม่มี "มิติเวลา" ของสารน้ำ** รู้ได้แค่ว่าตอนนี้เหลือเท่าไหร่ แต่ไม่รู้ว่าอีกนานแค่ไหนจะหมด ทำให้งานเปลี่ยน IV วางแผนล่วงหน้าไม่ได้ และถูกบังคับให้เป็นงานแทรกเสมอ

**Root Cause รอง (ฝั่งหัวหน้าหอ):** ภาระงานพยาบาลไม่เคยถูกวัด จึงบริหารกำลังคนด้วยความรู้สึก และขออัตรากำลังด้วยหลักฐานไม่ได้

# Problem Statement

## A. พยาบาลประจำการ

**ใคร** พยาบาลประจำการในหอผู้ป่วยสามัญ ที่ดูแลผู้ป่วยให้สารน้ำ 8–16 เตียงพร้อมกันในหนึ่งเวร

**มีปัญหา** ไม่รู้ล่วงหน้าว่าสารน้ำของแต่ละเตียงจะหมดเมื่อไหร่ รู้ได้แค่ "ตอนนี้เหลือเท่าไหร่" จากการเดินผ่านและมองด้วยตา จึงวางแผนรอบการเปลี่ยนถุงล่วงหน้าไม่ได้

**ส่งผลให้**
- งานเปลี่ยน IV กลายเป็นงานแทรก ต้องหยุดงานที่ทำอยู่กลางคัน (เตรียมยา/ทำแผล) → เป็นจุดเสี่ยงความผิดพลาด
- เดินซ้ำเส้นทางเดิมทีละเตียง แทนที่จะรวบไปเปลี่ยนทีเดียวหลายเตียง
- ในเวรที่งานหนัก รอบตรวจหลุด เกิดกรณีสารน้ำหมดค้าง
- ญาติรับรู้ว่า "เรียกแล้วไม่มา" กระทบความพึงพอใจ

**เกิดขึ้นเมื่อ** เวรที่อัตราส่วนพยาบาลต่อเตียงสูงที่สุด (เวรบ่าย/เวรดึก) · ช่วงส่งเวร · ช่วงที่พยาบาลติดงานที่หยุดกลางคันไม่ได้

**ความถี่**
- งานเปลี่ยน IV แบบแทรกนอกรอบ ~4–6 ครั้ง ต่อ เวร
- IV หมดค้างโดยไม่มีใครรู้ ~2–3 ครั้ง ต่อ สัปดาห์ ต่อ หอ
- ญาติเป็นคนแจ้งก่อน ~50–70% ของเคสทั้งหมด

---
## B. หัวหน้าหอผู้ป่วย

**ใคร** หัวหน้าหอผู้ป่วย ที่รับผิดชอบพยาบาล 12–18 คน และ 30+ เตียง

**มีปัญหา** ไม่มีข้อมูลเชิงปริมาณเรื่องภาระงานและเวลาตอบสนองของทีม มีแต่ "ความรู้สึกของน้องตอนส่งเวร"

**ส่งผลให้**
- จัดเวรด้วยความรู้สึก ไม่ใช่ข้อมูลภาระงานจริง
- ขออัตรากำลังเพิ่มไม่สำเร็จ เพราะไม่มีตัวเลขไปสู้
- รู้ว่ามีปัญหาก็ต่อเมื่อเกิด incident แล้ว

**เกิดขึ้นเมื่อ** ทุกรอบการจัดเวร · ทุกครั้งที่ต้องเสนอของบประมาณหรือชี้แจงเหตุการณ์ต่อฝ่ายการพยาบาล

**ความถี่**
- รอบจัดเวร 1 ครั้ง ต่อ เดือน
- รายงานภาระงาน 1 ครั้ง ต่อ เดือน (ทำจากความจำ)
